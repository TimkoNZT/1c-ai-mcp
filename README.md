# 1c-ai-mcp

MCP-прокси на основе **1C:Enterprise AI** (1С:Напарник).
Предоставляет 5 инструментов для работы с AI-ассистентом 1С через любого MCP-совместимого агента.

- **Ask** — задать вопрос AI-ассистенту по разработке 1С.
- **ReviewCode** — проверить код на ошибки и проблемы производительности.
- **FixCode** — исправить ошибки в коде.
- **ExplainCode** — объяснить назначение и логику кода.
- **GetResult** — получить продолжение ответа, если вызов любого инструмента не уложился в 30 с.

## Требования

- Node.js 22+
- Токен code.1c.ai

## Установка

- **Релиз**: скачайте `1c-ai-mcp_v<версия>.zip` из [последнего релиза](/releases/latest) и распакуйте.
- **Исходники**: `git clone` этот репозиторий, используйте `src/index.js`.

## Подключение

Добавьте MCP-сервер в конфигурацию вашего агента.

### Opencode

`opencode.json`:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "1c-ai-mcp": {
      "type": "local",
      "command": [
        "node",
        "/путь/к/1c-ai-mcp.js",
        "--mcp",
        "--token=<ваш-токен>"
      ],
      "enabled": true
    }
  }
}
```

### Claude Code

`.mcp.json` в корне проекта:

```json
{
  "mcpServers": {
    "1c-ai-mcp": {
      "command": "node",
      "args": ["/путь/к/1c-ai-mcp.js", "--mcp", "--token=<ваш-токен>"]
    }
  }
}
```

## Переменные окружения

| Переменная        | Описание                                 | По умолчанию         |
| ----------------- | ---------------------------------------- | -------------------- |
| `AI_TOKEN`        | Токен доступа к code.1c.ai               | —                    |
| `AI_SESSION_FILE` | Путь к кэшу сессии                       | .session-cache.json  |
| `AI_TRACE_LOG`    | Путь к логу трассировки                  | proxy_trace_*.log    |
| `AI_PROJECT_ROOT` | Корень проекта (файлы, доступные модели) | папка запуска агента |
| `AI_FULL_LOG`     | Полное логирование                       | false                |
