# 1c-ai-mcp

MCP-прокси на основе **1C:Enterprise AI** (1С:Напарник).
Предоставляет 5 инструментов для работы с AI-ассистентом 1С через любого MCP-совместимого агента.

- **Ask** — задать вопрос AI-ассистенту по разработке 1С.
- **ReviewCode** — проверить код на ошибки и проблемы производительности.
- **FixCode** — исправить ошибки в коде.
- **ExplainCode** — объяснить назначение и логику кода.
- **GetResult** — получить продолжение ответа, если вызов любого инструмента не уложился в 30 с.

## Требования

- Node.js 22+
- Токен code.1c.ai

## Установка

- **Релиз**: скачайте `1c-ai-mcp_v<версия>.zip` из [последнего релиза](https://github.com/TimkoNZT/1c-ai-mcp/releases/latest) и распакуйте.
- **Исходники**: `git clone` этот репозиторий, используйте `src/index.js`.

## Параметры запуска (CLI)

Прокси запускается как MCP-сервер: `node 1c-ai-mcp.js --token=<токен>`. Доступные аргументы:

| Аргумент          | Обязателен | Описание                                            | Альтернатива через env |
| ----------------- | ---------- | --------------------------------------------------- | ---------------------- |
| `--mcp`           | Нет        | Режим MCP. Оставлен для совместимости: режим всегда MCP | —                  |
| `--token=<токен>` | ✅ Да       | Токен доступа к code.1c.ai                          | `AI_TOKEN`             |
| `--full-log`      | Нет        | Включить логирование (трассировка запросов/ответов) | `AI_FULL_LOG = 1`      |

## Переменные окружения

| Переменная        | Обязательна | Описание                                                      | По умолчанию          |
| ----------------- | ----------- | ------------------------------------------------------------- | --------------------- |
| `AI_TOKEN`        | ✅ Да        | Токен доступа к code.1c.ai. См. параметр `--token`            | —                     |
| `AI_API_MODE`     | Нет         | Транспорт: `public` (документированный `/public/v1`) или `legacy` (внутренний `/chat_api/v1`, откат) | `public` |
| `AI_BASE_URL`     | Нет         | Базовый адрес API                                             | `https://code.1c.ai`  |
| `AI_FULL_LOG`     | Нет         | Включить логирование (`1`\|`true`). См. параметр `--full-log` | `false`               |
| `AI_PROJECT_ROOT` | Нет         | Корень проекта — какие файлы доступны модели                  | Папка запуска агента  |
| `AI_SESSION_FILE` | Нет         | Путь к кэшу Ask-диалога и списка конверсаций | `.session-cache.json` |
| `AI_TRACE_LOG`    | Нет         | Путь к файлу трассировки (при `--full-log`)                   | `proxy_trace_*.log`   |

По умолчанию используется публичный API 1С:Напарника. Если нужно вернуться на прежний внутренний транспорт, достаточно задать `AI_API_MODE=legacy` — остальные настройки и инструменты не меняются.

## Отложенные запросы

Если ответ не уложился в 30 секунд, инструмент возвращает `request_id` и уже накопленный текст. `GetResult` принимает:

- `request_id` — идентификатор задания; без него берётся последнее задание;
- `wait_seconds` — подождать новых данных до 25 секунд, чтобы получить результат одним вызовом.

Завершённые задания хранятся 30 минут, активные прерываются через 15 минут. После каждого `Ask` в ответ добавляется строка с заполненностью контекста:

```
📊 Контекст: ≈40k / 384k (10%)
```

Значения берутся из SSE-ответа (`details.usage`, `details.max_context_length`), дополнительных запросов нет.

## Подключение

Добавьте MCP-сервер в конфигурацию вашего агента или попросите его это сделать.

### Opencode

`opencode.json`:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "1c-ai-mcp": {
      "type": "local",
      "command": [
        "node",
        "/путь/к/1c-ai-mcp.js",
        "--token=<ваш-токен>"
      ],
      "environment": {
        "AI_PROJECT_ROOT": "/путь/к/проекту",
        "AI_API_MODE": "public"
      },
      "enabled": true
    }
  }
}
```

### Claude Code

`.mcp.json`:

```json
{
  "mcpServers": {
    "1c-ai-mcp": {
      "command": "node",
      "args": ["/путь/к/1c-ai-mcp.js", "--token=<ваш-токен>"],
      "env": {
        "AI_PROJECT_ROOT": "/путь/к/проекту",
        "AI_API_MODE": "public"
      }
    }
  }
}
```
